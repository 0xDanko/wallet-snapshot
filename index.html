// wallet snapshot

Historical token balances & USD values at a specific block · Ethereum · Gnosis · Base

⚠ Cannot run from file://
Your browser blocks API calls from local files. You need to serve this file over HTTP.
Open a terminal in the folder containing this file and run: python3 -m http.server 8080 Then open http://localhost:8080/wallet-balance-checker.html in your browser.

Tokens with USD value < $1.00 will be hidden. Prices fetched from CoinGecko historical data at snapshot time.
